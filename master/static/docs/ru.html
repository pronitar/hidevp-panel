О панели

HideVP Panel — панель для собственного VPN-сервиса на базе Xray-core. Одна master-панель управляет всем: серверами, VPN-подключениями, пользователями, Telegram-ботом, оплатами и обновлениями. На каждом VPN-сервере работает work-панель (агент): она получает настройки от master и запускает Xray.

ЧастьГде работаетЧто делает
Master-панельОдин сервер (можно в России)Админка, сайт пользователей, подписки, Telegram-бот, оплаты, резервные копии
Work-панельКаждый VPN-серверXray, подключения, учёт трафика и устройств, проверка сервера
Консоль hidevpЛюбой сервер с панельюУстановка, обновление, откат, домен, логи, восстановление доступа

Пользователь получает одну ссылку подписки. В ней все включённые подключения, и она работает в Happ, INCY и других клиентах Xray. Отключить, продлить или ограничить пользователя можно в админке — изменения применяются на всех серверах примерно за минуту, без перезапуска Xray.

Требования

  • VPS с Ubuntu 22.04/24.04 или Debian 11/12, доступ root по SSH. Хватит 1 ядра и 1 ГБ памяти.
  • Узлам нужен доступ к github.com: оттуда ставятся Xray-core и обновления.
  • Бот Telegram (создаётся у @BotFather).
  • Желательно — домен с A-записью на IP master-сервера. Без домена админка работает по http://IP:порт без шифрования.

Установка

На каждом сервере выполните одну команду — откроется меню установки:

bash <(curl -fsSL https://github.com/pronitar/hidevp-panel/releases/latest/download/install.sh)

Без доступа к GitHub: скачайте hidevp-panel-<версия>.zip из Releases, загрузите в /root и выполните cd /root && unzip -o hidevp-panel-*.zip && bash hidevp-panel/hidevp.sh.

Варианты установки

ВариантКогда выбирать
Только master-панельОтдельный сервер для управления (например, в России)
Только work-панельVPN-серверы в нужных странах
Обе на одном сервереОдин сервер и для управления, и для VPN. Порт 443 займёт сайт панели — для VPN берите 8443

Master-панель

  1. В меню выберите «Установить master-панель».
  2. Домен. Введите домен, если A-запись уже указывает на сервер. При работающем nginx панель добавит отдельный сайт и сертификат certbot, остальные сайты не затрагиваются; без nginx ставится Caddy. Enter — установка без домена на http://IP:случайный_порт. Домен можно подключить позже: hidevp → «Домен и сертификат».
  3. Сайт-заглушка. Установщик спросит, включить ли её. Рекомендуется: на главной странице будет обычный сайт, а вход пользователей переедет на секретный адрес (см. «Маскировка серверов»).
  4. В конце будут показаны адрес админки (со случайным секретным путём), логин и пароль — сохраните их.

Work-панель

  1. В меню выберите «Установить work-панель». Установятся Xray-core и агент, включится BBR.
  2. В конце будут таблица свободных портов и ключ NODE-….
  3. В админке: Серверы → Подключить сервер — вставьте ключ. Порт управления сразу закроется для всех, кроме IP master-панели.

Порты

СерверПортНазначение
master80, 443С доменом: сайт, админка, подписки
masterиз установкиБез домена: сайт, админка, подписки
узелиз установкиAPI work-панели, доступ только с IP master
узелпорты VPNTCP; Hysteria2 — UDP; Shadowsocks — TCP и UDP; «Свой сайт» — ещё 80/TCP

В ufw порты открываются автоматически. Если у хостера есть внешний фаервол, откройте порты там.

Консоль hidevp

Команда hidevp открывает меню: данные входа, смена логина и пароля, домен и сертификат, ключ узла, Xray (перезапуск, переустановка, проверка конфигурации, «Открыть API work-панели»), логи, обновление, откат, переустановка и удаление, язык.

hidevp-panel info               # адрес админки и логин
hidevp-panel reset-admin        # новые логин и пароль
hidevp-panel set-stub on|off    # сайт-заглушка
hidevp-node key | rotate        # ключ узла
journalctl -u hidevp-panel -f   # лог master
journalctl -u hidevp-node -f    # лог work-панели
journalctl -u xray -f           # лог Xray

Первая настройка

  1. Настройки — название сервиса, публичный адрес (с доменом — https://домен), контакт поддержки, лимиты по умолчанию. Смените пароль администратора.
  2. Серверы → Подключить сервер — ключ NODE-… каждого узла.
  3. VPN → Создать — сервер, протокол, транспорт, сайт маскировки. Порт подставится сам.
  4. Telegram-бот — токен, подключение администраторов, при необходимости маршрут через зарубежный сервер.
  5. Тарифы и оплата — сроки, цены, способы оплаты.
  6. Пользователи → Создать — тестовый пользователь; откройте его ссылку подписки в Happ.
  7. Серверы → Проверить у каждого сервера — все пункты должны быть зелёными.
  8. Резервные копии — включите автоматическое создание.

Серверы

Страница открывается сразу; состояние каждого сервера подгружается отдельно. На карточке: флаг страны, адрес, версии work-панели и Xray, нагрузка CPU, памяти и диска, число VPN.

  • Проверить — диагностика: Xray запущен, порты слушаются и доступны снаружи, фаервол, сайт маскировки, свой сайт и его сертификат, выход в интернет через каждое подключение, точность времени. Для красных пунктов показана подсказка.
  • SOCKS5 — прокси с логином и паролем только для администратора: ссылка socks5://, ссылка для импорта в приложения и прокси для Telegram. В подписку пользователей не попадает. Трафик не шифруется — используйте для своих задач.
  • Изменить — название, адрес, страна. Удалить — убирает сервер из панели (сам сервер не трогается).

Порт управления work-панели по умолчанию закрыт для всех, кроме IP master-панели. Если IP master сменился, на сервере: hidevp → Xray → «Открыть API work-панели».

VPN-подключения и шифрование

Одно подключение — это протокол, порт и маскировка на конкретном сервере. На сервере может быть несколько подключений; все включённые попадают в подписку в порядке поля «Порядок».

Протоколы

ПротоколШифрование и маскировкаКогда использовать
VLESS + RealityTLS 1.3 с обменом ключей X25519; Reality выдаёт сервер за выбранный сайт, чужие подключения перенаправляются на настоящий сайтОсновной вариант
Trojan + RealityТа же маскировка Reality, другой протокол внутриВторой вариант рядом с VLESS
Shadowsocks-20222022-blake3-aes-128-gcm, у каждого пользователя свой ключ; без маскировки под сайтРезерв, сети без глубокой фильтрации
Hysteria2QUIC/UDP с TLS, самоподписанный сертификат с закреплением (pinSHA256); опционально SalamanderПлохие сети, резерв по UDP. Нужен Xray 26.3.27+

Транспорты (VLESS и Trojan)

ТранспортОсобенности
TCP (+Vision для VLESS)Максимальная скорость, минимум задержки
XHTTPТрафик идёт обычными HTTP-запросами. Лучше всего переживает фильтрацию в России
gRPCПохож на трафик сервисов Google; запасной вариант

Поля формы

  • Порт — лучше 443; если занят — 8443 или 2053. Панель проверяет, что порт свободен и доступен снаружи, и предлагает свободные.
  • Сайт маскировки (SNI) — зарубежные сайты, российские сайты (для серверов в России), свой сайт (self-steal) или другой сайт.
  • Отпечаток TLS — Chrome по умолчанию.
  • Выход в интернет — с этого сервера или через подключение на другом сервере (каскад).
  • Перевыпустить ключи — новые ключи Reality и пароли; пользователям нужно обновить подписку.

Маскировка от блокировок

Надёжнее всего несколько разных подключений в подписке и включённый автовыбор: когда оператор блокирует один вариант, приложение уходит на другой.

Как блокируютЧто помогает
По IP зарубежного хостинга, связь «замерзает»Каскад через сервер в России, смена IP
Белые списки на мобильном интернетеКаскад через российский сервер крупного хостера
Несовпадение сайта маскировки и IPСвой сайт, сайт того же хостера
По имени сайта (SNI)Фрагментация TLS, другой сайт маскировки
По поведению трафикаXHTTP, Hysteria2

Свой сайт (self-steal)

  1. Создайте A-запись поддомена (например fr.ваш-домен.ru) на IP сервера, без проксирования Cloudflare.
  2. Порт 80 на сервере должен быть свободен или занят nginx master-панели.
  3. В VPN выберите SNI «Свой сайт на этом сервере» и введите домен. Панель поставит Caddy, получит сертификат Let's Encrypt и покажет простую страницу (текст можно заменить в /opt/hidevp-panel/node/data/site/<домен>/index.html).
  4. Через 1–2 минуты «Проверить» → пункт «Свой сайт … работает» должен быть зелёным.

Каскад

Телефон подключается к серверу в России, а тот пересылает трафик на подключение за рубежом. Для оператора это соединение внутри страны. Нужны work-панель 1.3.0+ на обоих серверах и VPS у крупного российского хостера. В VPN на российском сервере выберите российский SNI и «Выход в интернет → Через …». В подписке у каскада флаг страны выхода.

Автовыбор и фрагментация

Галочки вверху страницы VPN. Автовыбор добавляет в Happ и INCY пункт «⚡ Автовыбор»: приложение проверяет подключения (кроме Hysteria2) и выбирает самое быстрое работающее. Фрагментация TLS разбивает первый пакет с именем сайта на части. Для Happ и INCY подписка тогда выдаётся в формате Xray JSON — правила маршрутизации самого приложения не применяются.

Маскировка серверов

Настройки → «Маскировка серверов»:

  • Сайт-заглушка — главная страница домена показывает обычный сайт (личная страница, сайт в разработке, студия, файловое хранилище, проверка скорости, блог, технические работы или свой HTML). Вход пользователей — по секретному адресу кабинета, бот подставляет его сам. Неизвестные адреса отвечают как обычный nginx.
  • Сканеры — панель замечает IP, которые за 10 минут запрашивают 8 и больше несуществующих адресов. Их можно блокировать на 7 дней (404 на главной, в кабинете и при входе) и получать сводку в Telegram. Админка, подписки и личные страницы для заблокированных IP работают; IP администратора не блокируется.
  • Скрывать API work-панелей — порт управления на серверах открыт только для IP master-панели.

Подробные наборы настроек под разные ситуации — в разделе «Рекомендуемые наборы».

Рекомендуемые наборы

СитуацияПодключения в подписке
Один зарубежный сервер, есть доменVLESS + XHTTP + свой сайт (443/8443); VLESS + TCP + другой сайт; Hysteria2 + Salamander
Один зарубежный сервер, без доменаVLESS + XHTTP + сайт «соседа» по хостеру; Trojan + TCP + другой сайт; Hysteria2
Зарубежный + российский серверВсё выше + каскад: VLESS + XHTTP на российском сервере, SNI ya.ru или vk.com, выход через зарубежный
Белые списки на мобильномКаскад через российский сервер; прямые подключения — для Wi-Fi

Тестируйте на реальном операторе: обновите подписку на Wi-Fi, затем день-два пользуйтесь каждым подключением на мобильном интернете и отметьте, что живёт дольше. Лучшие поднимите в начало списка.

Пользователи

  • Создать — имя, срок в месяцах или бессрочно, лимит трафика (ГБ), лимит устройств, блокировка торрентов.
  • Статусы: активен, истёк, превышен трафик, приостановлен (превышен лимит устройств на 10 минут), отключён вручную.
  • Лимит устройств считает разные IP за последние минуты. Блокировка срабатывает, если превышение держится дольше 2,5 минут, — переключение Wi-Fi ↔ мобильный не мешает.
  • Действия: продлить, сбросить трафик, перевыпустить ссылки (старая подписка перестаёт работать), написать в Telegram, история оплат.
  • Страница пользователя — личная ссылка /u/…: статус, срок, трафик, QR-код, кнопки «Добавить в Happ / INCY», продление.
  • Ссылка подписки /sub/… — одна на все подключения; Happ, INCY, v2rayNG, Hiddify, NekoBox и другие клиенты Xray.
  • Вход на сайт — по номеру телефона: код приходит в бота. Номер привязывается, когда пользователь отправляет его боту.

Telegram-бот

  1. Создайте бота у @BotFather (/newbot) и скопируйте токен.
  2. Админка → Telegram-бот → вставьте токен → «Сохранить».
  3. Подключение к Telegram. Если master в России и Telegram недоступен — «Через подключённый сервер (для России)» и зарубежный узел, или «Через прокси» (socks5:// — подойдёт SOCKS5 одного из ваших серверов).
  4. Подключить мой Telegram — получите код и отправьте его боту: вы станете администратором бота и будете получать уведомления об оплатах, переводах, новых пользователях и ошибках. Код действует ограниченное время и сбрасывается после 5 неверных попыток.

Бот для пользователей

  • /start — бот создаёт пользователя; подписка начинает работать после оплаты, промокода или продления администратором. Чтобы входить на сайт, пользователь отправляет боту номер телефона.
  • Меню — моя подписка (статус, срок, трафик, ссылка, QR), купить или продлить, перевыпустить ссылки, инструкции, поддержка, язык.
  • Кнопки и тексты — в админке можно включать и выключать кнопки меню, менять их порядок, тексты и добавлять свои кнопки со ссылками.
  • Чистый чат — бот удаляет старые сообщения меню, чтобы в чате не копилась история.
  • Уведомления — за 3 дня до окончания подписки и в момент окончания; превышение лимита устройств.

Тарифы и оплата

  • Тарифы — сроки от 1 до 24 месяцев. Для каждого задаются цены в звёздах и в валюте (₽, $, €, ₸, ₴, Br).
  • Звёзды Telegram — работают сразу, настройка не нужна.
  • Карта (провайдер Telegram) — подключите платёжного провайдера в @BotFather → Payments и вставьте «Токен провайдера».
  • CryptoBot — в @CryptoBot: Crypto Pay → Создать приложение → скопируйте токен. Оплата проверяется каждые 20 секунд.
  • ЮKassa — карты, СБП и SberPay на странице ЮKassa. Нужен договор с ЮKassa; shopId и секретный ключ — в личном кабинете: Интеграция → Ключи API. Можно отправлять чеки по 54-ФЗ: на привязанный телефон пользователя или на e-mail из настроек. Оплата проверяется каждые 20 секунд.
  • Platega — СБП и карты. Merchant ID и секретный ключ — в личном кабинете Platega. Способ можно выбрать заранее или оставить выбор покупателю.
  • ЮMoney — перевод на ваш кошелёк, без ИП и договора. Укажите номер кошелька, затем на странице yoomoney.ru/transfer/myservices/http-notification вставьте адрес уведомлений из админки и скопируйте секрет в панель. Подписка продлевается, как только приходит уведомление о переводе. Нужен публичный адрес панели.
  • ЮKassa, Platega и ЮMoney принимают только рубли — выберите валюту RUB.
  • Переводы — укажите реквизиты карты или СБП. Пользователь получает уникальный код для комментария и нажимает «Я оплатил»; вы сверяете поступление и подтверждаете в боте или в админке.
  • Оплата с сайта — на странице пользователя те же тарифы и способы.

Перед оплатой панель проверяет цену, валюту и промокод; повторный платёж не засчитывается. Каждая оплата продлевает подписку на выбранный срок и снимает приостановку.

Промокоды

Скидка 1–100 %, тарифы, срок действия, лимит использований, одноразовые и многоразовые, только для новых пользователей. Промокод 100 % активирует подписку без оплаты.

Рост: пробный период, рефералы, возврат

Раздел «Рост» в меню.

  • Пробный период — новые пользователи бота получают N бесплатных дней. Один раз на Telegram-аккаунт и только тем, кто ещё не платил. С флажком «после номера телефона» пробный период выдаётся, когда пользователь поделится номером, и один раз на номер.
  • Рефералы — у каждого пользователя в боте («Пригласить друга») и на личной странице есть ссылка вида t.me/бот?start=r_ID. Когда приглашённый впервые оплатит подписку, пригласивший получает заданное число дней, а приглашённый — свой бонус, если он задан.
  • Источники — ссылка t.me/бот?start=s_метка отмечает, откуда пришёл новый пользователь. Таблица показывает по каждой метке регистрации, оплативших и выручку. Ссылку с меткой можно собрать прямо на странице.
  • Возврат ушедших — через N дней после окончания подписки бот присылает личный одноразовый промокод со скидкой; промокод уже применён, пользователю остаётся нажать «Продлить со скидкой». Только тем, кто раньше платил.
  • Причина ухода — на следующий день после окончания подписки бот спрашивает, почему человек не продлил, с готовыми вариантами. Ответы видны в разделе «Рост» и в карточке пользователя.

Прокси для Telegram (MTProto)

На любом сервере можно включить MTProto-прокси: Серверы → кнопка «MTProto» на карточке сервера. Укажите порт и сайт для маскировки — прокси выглядит как HTTPS-сайт (Fake TLS), а чужие подключения уходят на этот сайт. Для сервера в России берите российский сайт.

Прокси получают все пользователи с активной подпиской: кнопка «Прокси для Telegram» в боте и на личной странице. Telegram добавляет прокси сам, VPN-приложение не нужно. У каждого пользователя свой секрет; когда подписка заканчивается, его прокси перестаёт работать. Кнопка «Новые секреты» меняет секреты у всех. Нужна work-панель 1.7.0.

Мониторинг и лимиты серверов

Настройки → «Мониторинг». Администраторы получают сообщения в Telegram, когда сервер недоступен дольше заданного времени и когда он вернулся, когда остановился Xray, когда диск или память заполнены больше порога. Xray, диск и память проверяются на work-панели 1.7.0.

Лимит трафика хостера

Серверы → «Изменить»: объём в ГБ, период (месяц или сутки), день начала месяца и что считать — весь трафик или только исходящий, как считает хостер. Панель считает трафик сетевого интерфейса сервера. Когда лимит исчерпан, сервер убирается из подписок до начала нового периода, а администраторы получают сообщение. Если других серверов нет, сервер остаётся в подписках. Счётчик можно обнулить вручную.

Скрытие недоступных серверов

Настройки → «Подписки и устройства» → «Скрывать из подписки серверы, которые не на связи». Сервер пропадает из подписки, если не отвечает дольше 3 минут, и возвращается сам. Все серверы сразу никогда не скрываются.

Уведомления и статистика

  • Уведомления — технические работы и новости с датой начала и окончания и аудиторией (все, с активной или с истёкшей подпиской). Показываются на странице пользователя, в боте и в приложениях; можно разослать в Telegram.
  • Статистика — выручка, оплаты и пользователи за период, фильтры по способу оплаты и тарифу, графики, выгрузка в CSV.

Резервные копии

  • Автоматически — раз в день, неделю или месяц; задаётся число хранимых копий.
  • Вручную — полная копия или выборочно: пользователи, серверы, VPN, статистика, оплаты, промокоды, уведомления, настройки.
  • Восстановление — «Обновить данные» (объединить с текущими) или «Заменить». Логин администратора, адрес и путь админки не меняются; текущая база сохраняется перед восстановлением.
  • Копии хранятся в /opt/hidevp-panel/master/data/backups/. Полная копия содержит ключи узлов и токены — храните её в надёжном месте.

Обновления

  • Новые версии публикуются только в релизах GitHub и подписаны ключом Ed25519 автора. Master проверяет подпись и контрольную сумму, work-панели — подпись релиза.
  • Обновления → master-панель — окно с полосой 0–100 %, шагами и журналом. Пока идёт обновление, админка заблокирована. Если установка не удалась, автоматически возвращается предыдущая версия.
  • Серверы — «Обновить до …» у каждого сервера. Клиенты VPN не отключаются.
  • Откат — «Откатить…» у master и «Другая версия…» у сервера. На свой страх и риск: перед откатом master база сохраняется.
  • Без доступа к GitHub — загрузите архив релиза в /root и выберите hidevp → «Обновить панель».

Настройки

  • Общие — название сервиса (видно в приложениях), публичный адрес, контакт поддержки, лимиты трафика и устройств по умолчанию.
  • Учётная запись — логин и пароль администратора. Порт, секретный путь и домен меняются в консоли hidevp.
  • Приложения Happ и INCY — вид и поведение подписки в приложениях, см. раздел ниже.
  • Маскировка серверов — сайт-заглушка, вид страницы, заголовок, адрес кабинета, скрытие API work-панелей.
  • Оформление — язык (русский/английский) и 4 темы, кнопки вверху страницы.

Приложения Happ и INCY

Настройки → «Приложения Happ и INCY» управляют тем, как подписка выглядит и ведёт себя в приложениях. Изменения доходят до устройства при следующем обновлении подписки (кнопка обновления в приложении или автообновление).

Переменные в названиях

В названии VPN можно использовать {server}, {user}, {days}, {left}, {used}, {total}, {expire} — панель подставит значения для каждого пользователя, например «Нидерланды · осталось {days} дн.». Значения обновляются вместе с подпиской.

Устройства по HWID

Настройки → «Подписки и устройства». Устройства можно считать по IP (сколько адресов подключено одновременно), по HWID (сколько приложений получают подписку) или обоими способами. Happ и INCY присылают HWID; когда лимит устройств занят, новое приложение получает пустой список серверов и сообщение. Пользователь сам отвязывает старое устройство на личной странице или в боте («Мои устройства»), администратор — в карточке пользователя. Устройство, которое долго не обновляло подписку, освобождается само. Перевыпуск ссылок отвязывает все устройства.

Подписи под серверами

В настройках VPN поле «Подпись под названием в приложении» (до 30 символов) заменяет строку с протоколом, например «Для YouTube и соцсетей». Пусто — приложение покажет протокол.

Provider ID для Happ

Часть функций Happ работает только у провайдеров с Provider ID: подписи под серверами, предупреждение об окончании подписки с кнопкой продления, запрет просмотра настроек серверов. Зарегистрируйтесь на happ-proxy.com, скопируйте ID из профиля и вставьте в поле «Happ Provider ID». INCY показывает подписи без него.

Безопасность

  • Админка на случайном секретном пути. Пароль хранится как хеш scrypt, сеансы — как хеш SHA-256. После 5 неверных попыток вход с IP блокируется на 10 минут, после 50 неудачных попыток со всех IP — для всех.
  • Cookie HttpOnly, SameSite=Strict, при HTTPS — Secure; проверка Origin, CSP, запрет встраивания, HSTS, ограничение размера запросов.
  • Вход на сайт: код из 6 цифр на 5 минут, 5 попыток, лимиты на номер, IP и сервер. Ответ одинаковый для существующих и несуществующих номеров.
  • Связь master → узлы: HTTPS с закреплённым сертификатом и 256-битным ключом; порт управления открыт только для IP master.
  • Обновления только подписанные. Входные данные (домены, пути, имена сервисов) проверяются, чтобы их нельзя было подставить в конфигурации.
  • База, резервные копии, ключи и логи доступны только root.

Рекомендации

  • Используйте домен и HTTPS для админки.
  • Войдите по SSH-ключу и отключите вход по паролю; смените стандартный порт SSH.
  • Храните резервные копии вне сервера.
  • Регулярно обновляйте панели и систему (apt upgrade).
